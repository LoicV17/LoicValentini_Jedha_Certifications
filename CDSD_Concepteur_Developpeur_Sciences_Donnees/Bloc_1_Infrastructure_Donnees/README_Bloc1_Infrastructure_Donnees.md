# 📊 Bloc 1 – Infrastructure données

Ce dossier contient le projet réalisé dans le cadre du **Bloc 1 – Infrastructure données ** de la certification **CDSD – Concepteur Développeur en Sciences des Données** (Jedha / RNCP 35288).  
Ce bloc vise à maîtriser les fondamentaux de l’analyse de données, de l’exploration statistique à la visualisation avancée.

---

## 🧪 Projet inclus

### 🔹 Kayak Project – Collecte, stockage et analyse des données Kayak
Construction d'une architeccture permettant la prise de décision concernant des hotels :

- Collecte via API d'informations géographiques et météorologiues
- Scraping de données hôtelières
- Analyse de données et prise de dcisions stratégiques
- Stockage dans un data-lake cloud AWS S3
- Transfert vers base de données AWS RDS et postgreSQL

📁 Dossier : `Kayak_project/`
